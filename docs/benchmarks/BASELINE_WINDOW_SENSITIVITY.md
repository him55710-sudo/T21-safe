# Baseline window sensitivity — synthetic hospital case

**Status:** engineering sensitivity only  
**clinical_validation:** `false`  
**clinical window choice:** `PI_TO_DEFINE`  
**Data:** deterministic synthetic hospital case only; no Fantasia or VitalDB

`t21_engine.evaluation.baseline_window_sensitivity` compares summaries from the
immediately preceding 180-second and 300-second stable windows. Both windows end at
the synthetic anesthesia-stage `induction.start_s` timestamp, which is research
metadata only. This comparison does not select a clinical window or produce dosing,
alerts, treatment guidance, or clinical decisions.

## Machine-readable result

The report schema is `baseline-window-sensitivity/1.0`. Each row contains `metric`,
`source_channel`, `window_180_value`, `window_300_value`,
`absolute_delta_300_minus_180`, and `relative_delta_pct_300_minus_180`. Metrics are
HR derived from ECG II, the available ABP median exposed as `map_or_abp`, and SpO2.
The relative delta denominator is the absolute 180-second summary.

Top-level safety fields are `synthetic_only=true`, `clinical_validation=false`,
`clinical_window_choice=PI_TO_DEFINE`, and a `safety` object with dosing, alerts, and
clinical decisions disabled.

## Fail-closed behavior

No metric rows are emitted on failure. Stable reason codes are:

| Code | Meaning |
| --- | --- |
| `NON_SYNTHETIC_OR_PHI_CASE` | Input is not the labeled synthetic/no-PHI case |
| `MISSING_REQUIRED_CHANNEL` | A fixture channel required by alignment or this comparison is absent |
| `CASE_ALIGNMENT_FAILURE` | Synthetic channel clocks or arrays fail integrity checks |
| `MISSING_INDUCTION_START` | Exactly one finite induction-start timestamp is unavailable |
| `INSUFFICIENT_PREINDUCTION_WINDOW` | Fewer than 300 seconds precede induction or a window lacks expected samples |
| `MISSING_OR_NONFINITE_CHANNEL_DATA` | HR/ABP/SpO2 source data are missing or non-finite in a window |
| `BASELINE_CALIBRATION_FAILURE` | The shared baseline calibrator withholds calibration or required summaries |

The numeric output is generated by the testable module rather than copied into this
document, preventing a stale benchmark table from being mistaken for current output.
