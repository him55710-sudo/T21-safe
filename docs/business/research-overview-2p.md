## 1. 문제 (Problem)

다운증후군(T21) 환자는 마취·진정 과정에서 **이질적인 심폐·자율신경 표현형**을 가질 수 있어, 인구 평균 임계값만으로는 환자별 변화를 설명하기 어렵습니다. T21 Safe는 **환자별 다중 생체신호(ECG, PPG, BP, SpO2, EtCO2/호흡 등)의 시간 정렬·품질·단계별 변화**를 연구합니다.

**의도된 사용(Path B):** 보조 모니터링·연구용 의사결정 **지원 연구**. closed-loop·투약 권고·임상 허가 제품 주장이 아닙니다.

대상 환경(초안): 권역장애인구강진료센터 · 대학 치과병원 · 소아병원 · 마취·치과마취 연구팀 — 구체 기관은 `PI_TO_DEFINE`.

## 2. 기존 근거의 긴장: E1 vs E2

공개 문헌만으로도 **방향이 다른 두 축**이 동시에 존재합니다. 이 긴장을 숨기지 않는 것이 첫 PI 대화의 핵심입니다.

### E1 — 특정 맥락에서 혈역학 변화가 더 자주 보고됨

**FACT (검증된 claim 요약, Master `P2A-CLAIM-RQ001-01` VERIFIED):**  
소아 DS에서 sevoflurane 흡입 유도(및 관련 유도 노출) 시 비교군 대비 **서맥 발생이 더 높다**는 보고가 반복됩니다.

| ID | 비고 |
| --- | --- |
| PMID:40376277 | Prospective observational · sevoflurane induction bradycardia (E1) |
| PMID:20736433 | Kraemer 2010 · DS independent in multivariate |
| PMID:21109130 | Bai 2010 · matched higher prevalence/severity |
| PMID:15330954 | Borland 2004 · induction bradycardia |

**한계:** 절대 발생률은 서맥 **정의·시대**에 따라 크게 다름. 대부분 sevoflurane/유도 중심. **용량·투약 조언으로 해석 금지.**

관련: procedural sedation에서 비교군 대비 큰 혈압 감소 보고(PMID:40704557) — 임상적 의미는 아직 불확실.

### E2 — “항상 위험하다”로 단정할 수 없음

단일기관 DS 소아 **비심장** 마취 코호트에서 **전체 합병증률이 낮게** 보고된 바 있고, 내부 non-DS 대조가 없는 설계도 있습니다(PMID:40363932).  
반복 마취 비율이 높다는 기술도 있음(계획서 [E2] 수치 — **원문 재확인 `PI_TO_DEFINE`**).

**해석 (INTERPRETATION):** 문제는 “DS 마취는 항상 위험하다”가 아니라,

1. 특정 상황의 변화를 **환자별·시간 정렬 다중 신호**로 재현할 수 있는가?
2. artifact·환기·약물·기도/시술 사건을 구분할 수 있는가?
3. 공개 non-DS로 pipeline만 검증한 뒤 **병원 DS 자료에서 독립 검증**할 수 있는가?

## 3. 첫 연구 = 이용 가능성 + 단계별 변화 (예측 아님)

### 제안 제목 (초안)

> 다운증후군 소아의 마취·진정 과정에서 생체신호 자료의 **이용 가능성**과 **단계별 변화**: 과거 자료 기반 탐색 연구

| 항목 | 설계 |
| --- | --- |
| 대상 | 진단 확인된 DS · 마취/진정 — 연령·포함기준 `PI_TO_DEFINE` |
| 기간 | 가능하면 최근 5–10년 `PI_TO_DEFINE` |
| 1차 목적 | (A) 신호·타임스탬프 **이용 가능성/품질** (B) induction–maintenance–emergence–PACU **단계별** 기술통계 |
| 1차가 아닌 것 | 사건 **조기예측** · 임상 성능 AUC 주장 · RII를 확률로 제시 |
| 분석 순서 | 품질 보고서 → 환자별 변화 설명 → (충분 시) 비교 → **마지막에만** 예측 검토 |
| 사건 분리 | 심장·혈압 / 호흡·산소 / 의료진 처치 사건을 **한 점수로 합치지 않음** |

### 중단·축소 기준 (계획 §6-3 요약)

- DS 진단을 코드만으로 추정해야 하면 중단/축소
- 신호–마취기록 **시간 연결 불가** → 예측 연구 중단, 사례 수 기술만
- 핵심 신호가 선택적으로만 저장 → 편향 심하면 모델 금지
- 사건 시각 신뢰 불가 → 빈도 기술만, 조기예측 금지

## 4. 금지 주장 (PI 첨부 필수)

- DS 합병증 **예방** / 심정지·서맥·저혈압 **정확 예측**
- 마취제·propofol **용량 최적화** 또는 약물 **추천**
- T21 출력으로 **시술 안전** 판단 / **일반 병원** DS 마취 안전 주장
- 공개 non-DS로 **DS·소아 성능 검증** 주장
- Research Instability Index를 **확률·진단·예후·알람**으로 제시

권장 대체: “연구용 재생 · 후보 연관 · 명명된 공개 코호트 기술 검증 · DS 보정/임상 검증 없음.”
