# 병원 공동연구 PoC 제안서

**문서 상태:** 창업자 검토용 초안 · 병원/연구책임자와 범위 협의 전

**용도:** 연구 인프라와 자료 활용 가능성을 확인하는 소규모 사전 검토

**운영 원칙:** 연구용 · 병원 내부 설치 · 관찰 전용 · 임상 검증 아님

## 한 문장 제안

병원이 보유한 마취·진정 생체신호를 안전하게 정리하고, 시간축과 신호품질을 확인하여 후속 공동연구가 가능한지 함께 판단합니다.

이 PoC는 환자 위험을 예측하는 인공지능 시험이 아닙니다. 진단, 경보, 투약 권고, 시술 가능 여부 판단도 하지 않습니다.

## 병원과 함께 확인할 질문

- 필요한 자료가 기관 안에 어느 정도 있는가?
- 서로 다른 장비와 기록의 항목·단위·시간을 일관되게 해석할 수 있는가?
- 분석에 쓸 수 있는 신호와 쓸 수 없는 신호를 구분할 수 있는가?
- 비식별 처리, 접근 권한, 보존 기간과 반출 제한을 지킬 수 있는가?
- 더 큰 규모의 연구를 제안할 근거가 생겼는가, 아니면 먼저 보완할 항목이 있는가?

## 제안하는 3단계

### 1. 집계 확인

환자별 자료를 받기 전에 기관의 기존 분류와 소수집단 보호 원칙에 따라 사례 수, 신호 보유 여부, 반복 사례, 장비·자료 형식 변경 이력을 집계로 확인합니다. 이름, 진료번호, 정확한 날짜 등 개인 식별정보와 환자별 행은 요청하지 않습니다.

### 2. 자료 구조와 시간축 시험

기관 승인 아래 합성 자료 또는 허용된 소수의 비식별 예시로 다음을 확인합니다.

- 항목명, 자료형, 단위, 결측값 의미
- 환자·사례·장비 기록의 연결 방식
- 시간대, 장비 시계, 시간 보정과 불확실성
- 직접 식별정보와 불필요한 자유서술의 부재
- 같은 절차를 반복했을 때 같은 결과가 나오는지

이 단계의 기술적 통과는 전체 자료 추출이나 임상적 유효성을 승인하지 않습니다.

### 3. 승인된 범위의 추출 제안

앞선 두 단계가 충분하고 연구책임자, 기관 자료관리자, 정보보호 담당자의 승인이 확인된 경우에만 필요한 최소 범위의 비식별 추출을 별도로 제안합니다. 연구 질문, 포함 대상, 평가 기준과 통계 계획이 정해지기 전에는 범위를 넓히지 않습니다.

## PoC 운영 경계

| 항목 | 원칙 |
| --- | --- |
| 목적 | 연구 인프라와 자료 활용 가능성 확인 |
| 설치 | 병원 통제 환경의 로컬 설치를 기본으로 함 |
| 사용 방식 | 관찰 전용. 기존 모니터와 진료 흐름에 개입하지 않음 |
| 자료 소유 | 원자료는 병원이 소유·보관 |
| 외부 전송 | 기관 승인 없는 환자자료·원파형 외부 전송 금지 |
| 임상 사용 | 진단, 예측, 경보, 치료·투약 권고, 장비 제어 금지 |
| 결과 해석 | 연구 가능성에 관한 기록이며 임상 성능이나 제품 효능의 증명이 아님 |

## PoC 산출물

- 자료 보유 현황과 미해결 질문을 정리한 집계 검토표
- 자료 사전, 연결키, 시간축과 장비 변경 이력을 정리한 구조 검토표
- 신호 누락·잡음·사용 불가 사유를 포함한 품질 보고서
- 개인정보 보호, 접근 권한, 보존·삭제와 반출 조건 기록
- 후속 단계 제안: 진행, 조건부 진행, 보완 후 재검토, 중단 중 하나와 그 근거

## 성공의 의미

성공은 높은 예측 성능을 뜻하지 않습니다. 다음을 근거와 함께 답할 수 있으면 PoC 목적을 달성한 것입니다.

1. 승인된 연구 질문에 필요한 자료가 있는가?
2. 자료 구조와 시간축을 재현 가능하게 해석할 수 있는가?
3. 신호품질이 부족할 때 결과를 숨기거나 제외할 수 있는가?
4. 개인정보·기관 보안 조건을 지키는 운영 경로가 있는가?
5. 다음 단계의 범위, 책임자와 미해결 조건이 명확한가?

사례 수, 허용 오차, 통과 기준은 근거와 기관 정책 없이 이 제안서에서 임의로 정하지 않습니다.

## 데모에서 말할 수 있는 범위

합성 자료 또는 출처가 명확한 공개 심전도 자료로 다음 두 가지만 설명합니다.

- 정해진 방법에 따라 심박 사건을 찾아 시간순으로 정리하는 과정
- 신호품질지수(SQI)로 분석 가능한 구간과 부족한 구간을 구분하는 과정

이는 기능과 연구 절차의 시연입니다. 다운증후군 환자, 소아 마취, 특정 병원에서의 성능을 입증하지 않으며 합병증·서맥·심정지의 발생 가능성을 예측하지 않습니다.

## 역할과 착수 전 확인

| 주체 | 확인할 사항 |
| --- | --- |
| 병원 연구책임자 | 연구 질문, 대상과 평가 기준, 결과 해석 범위 |
| 자료관리자/정보보호 담당 | 비식별 방식, 전달 경로, 접근자, 보존·삭제 정책 |
| 병원 실무 담당 | 자료 사전, 장비·자료 형식·시계 변경 이력 |
| T21 연구팀 | 로컬 연구 도구, 재현 절차, 품질·한계 보고 |
| 창업자 | 기관 연락, 범위·일정·비용 협의와 최종 발송 승인 |

착수 전 연구윤리심의, 자료이용계약, 보안 검토의 필요 여부와 책임자를 기관 정책에 따라 확인합니다. 이 문서는 법률·규제 자문이나 계약서가 아닙니다.
