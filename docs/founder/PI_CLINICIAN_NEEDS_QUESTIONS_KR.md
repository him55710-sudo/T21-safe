## 면담 목적

1. 의사가 **실제로** 막히는 순간을 듣는다.
2. “실시간 위험 점수”가 필요한지, 다른 연구 산출물이 더 필요한지 솔직히 가린다.
3. 첫 연구 질문을 **서술·재현성** 쪽으로 2–3개까지 좁힌다.
4. 잠금 표([PI 의사결정 팩](PI_DECISION_PACK_KR.md))에 넣을 **미결/좁힘**만 남긴다. 코드 숫자·임계값은 이 자리에서 정하지 않는다.

## 약속하지 않는 것

- 진단, 예후, 진료 경보, 투약·마취 변경, 시술 가능 여부
- 공개·합성 자료 결과를 우리 병원 DS 성능처럼 말하기
- 근거 없는 일정·성능 수치
- 면담만으로 기능 개발 재개(unfreeze)
