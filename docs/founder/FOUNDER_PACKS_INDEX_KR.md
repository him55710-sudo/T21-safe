# 창업자 문서 모음

병원·연구자·투자자와 대화할 때 쓰는 쉬운 한국어 문서입니다. 모든 문서는 **연구용·로컬·관찰 전용**을 전제로 하며, 임상 예측이나 진료 경보를 주장하지 않습니다.

## 바로 고르기

| 상황 | 문서 | 쓰는 방법 |
| --- | --- | --- |
| 병원에 PoC 목적과 범위를 설명할 때 | [병원 공동연구 PoC 제안서](../business/HOSPITAL_POC_PROPOSAL_KR.md) | 연구 인프라·자료 가능성 중심으로 설명하고, 기관별 빈칸은 합의 후 채움 |
| 직접 데모를 진행할 때 | [창업자용 쉬운 데모 안내서](DEMO_GUIDE_KR.md) | 30초 소개, 3분 대본, 질문 답변과 금지 문장을 사전 점검 |
| 투자자 발표자료를 만들 때 | [투자자 설명자료](../business/IR_DECK_KR.md) | 슬라이드별 문안을 옮기되 시장·성능·매출 수치는 출처 없이 추가하지 않음 |
| 연구책임자 회의를 준비할 때 | [연구책임자 의사결정 팩](PI_DECISION_PACK_KR.md) | 대상, 평가 사건, 자료·검증 계획의 선택지와 미결 사항을 기록 |

## 공통 핵심 문장

> “T21 Safe는 병원 안의 마취·진정 생체신호를 정리하고 품질을 확인해 재현 가능한 공동연구를 돕는 연구 도구입니다. 현재는 환자 위험을 예측하거나 진료 경보를 제공하는 제품이 아닙니다.”

## 자료 협력 순서

1. [병원 집계 가능성 질의서](../business/HOSPITAL_AGGREGATE_FEASIBILITY_QUERY_KR.md)로 환자별 자료 없이 보유 현황을 확인합니다.
2. [자료 구조·시간축 시험 기준](../research/SCHEMA_CLOCK_PILOT_ACCEPTANCE.md)에 따라 합성 또는 허용된 비식별 예시를 점검합니다.
3. 연구책임자와 기관의 승인이 확인된 뒤 필요한 최소 추출만 별도로 제안합니다.

집계 회신이나 소규모 시험의 기술적 통과만으로 전체 추출, 임상 검증 또는 진료 사용을 승인하지 않습니다.

## 데모의 허용 범위

- 합성 또는 출처가 명확한 공개 심전도 자료
- 정해진 방법에 따른 심박 사건 정리
- 신호품질지수(SQI)에 따른 사용 가능 구간 확인

공개·합성 자료의 결과를 다운증후군, 소아 마취 또는 특정 병원에서의 임상 성능으로 설명하지 않습니다. 연구 점수는 사건 확률, 진단, 예후, 경보 또는 치료 기준이 아닙니다.

## 보내기 전 확인

- [ ] 실제 환자 식별정보, 자유서술 병력, 계정정보가 없다.
- [ ] 합성·공개·비식별 자료의 구분과 출처가 명확하다.
- [ ] 예측, 예방, 진단, 투약, 시술 가능 여부를 주장하지 않는다.
- [ ] 시장 규모, 성능, 계약, 매출과 일정 수치에 확인 가능한 출처가 있다.
- [ ] 기관명, 담당자와 승인 상태를 추정해서 채우지 않았다.
- [ ] 외부 발송과 병원 연락은 창업자가 직접 승인한다.
