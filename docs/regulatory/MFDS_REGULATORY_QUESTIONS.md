# MFDS 사전상담 질문서

문서 상태: 사전상담 준비 초안<br>
기준일: 2026-09-02<br>
현재 단계: RUO / silent shadow mode

## 상담 목표

T21 Safe의 현재 연구 프로토타입과 장래 임상 기능을 명확히 분리하고, 디지털의료제품법 체계에서 제품 해당성·품목·등급·임상시험·허가자료 범위를 MFDS와 조기에 합의한다. 본 문서는 품목이나 등급을 자체 확정하지 않는다.

## 기관에 먼저 제시할 기능 요약

- ECG, PPG/SpO2, 혈압 등 생체신호를 읽기 전용으로 수집하고 deterministic pipeline과 버전 고정 통계·ML 모델로 분석한다.
- LLM은 문헌 정리와 개발 검토에만 쓰며 환자별 계산에는 쓰지 않는다.
- 현재는 결과를 치료팀에게 숨기는 silent shadow 연구만 수행한다.
- 현재 출력은 진단·치료·투약·의료기기 제어를 하지 않는다.
- 장래 가설은 다운증후군 환자의 마취 유도 중 사전 정의된 혈역학적 불안정 패턴을 의료진에게 보조적으로 표시하는 것이다. 기능·표현·사용자는 미확정이다.

분류: `PRODUCT_ASSUMPTION`

## 핵심 질문

### 1. 제품 해당성·품목·등급

1. 현재 silent shadow 연구 소프트웨어와 장래 실시간 보조표시 기능은 각각 디지털의료기기 또는 임상시험용 디지털의료기기에 해당하는가?
2. 장래 기능의 정확한 품목명, 분류번호와 등급을 판단하려면 어떤 intended-use 문구와 위험정보가 필요한가?
3. 다운증후군·소아·마취 유도·실시간 생체신호 분석이라는 조합이 등급 또는 심사경로에 미치는 영향은 무엇인가?
4. 단일 소프트웨어로 볼지, 데이터 수집 게이트웨이·분석 소프트웨어·표시 UI를 별도 구성품으로 볼지 어떤 기준을 적용하는가?
5. 기존 환자감시장치의 경보를 대체하지 않고 읽기 전용으로 연결되는 경우에도 요구되는 상호운용성 자료는 무엇인가?

### 2. 연구와 임상시험

6. 결과가 치료팀에 공개되지 않는 전향 silent-mode 성능연구에 디지털의료기기 임상시험 승인, 기관 IRB, 신고 또는 별도 절차 중 무엇이 필요한가?
7. 후향적 비식별 데이터 개발, 전향 silent validation, 제한적 human-factors 연구를 각각 어떤 단계로 구분해야 하는가?
8. 다기관 외부검증 전에 단일기관에서 최소한 확인해야 할 기술·임상 성능은 무엇인가?
9. 다운증후군이라는 희귀 하위집단에서 비교군 구성, 사건 수, 반복 마취의 환자내 상관과 소아 연령층화를 어떤 수준으로 요구하는가?
10. 판정위원회(blinded adjudication)를 이용한 혈역학적 사건 라벨이 적절한가? 원 모니터 경보 또는 처치 기록을 참조표준으로 사용할 때 필요한 편향 통제는 무엇인가?

### 3. 임상 성능과 주장

11. 현재 후보 종말점(환자 단위 민감도·특이도, false alerts per hour, 리드타임, AUROC/AUPRC, 보정, 무출력률) 중 필수 성능지표는 무엇인가?
12. 알림을 도입할 경우 event-based와 time-in-warning 평가, 경보부담, lead-time 분포를 어떻게 제시해야 하는가?
13. 임상적 유용성을 주장하려면 silent validation 이후 어떤 전향 비교설계와 임상결과가 필요한가?
14. 인종·연령·선천성 심장질환·기저 심박수·마취법·기관별 하위군 성능의 허용 가능한 근거 범위는 무엇인가?

### 4. AI/ML 및 변경관리

15. 잠긴(locked) ML 모델에 요구되는 학습자료 대표성, 독립시험, 추적성, 과적합·데이터누출 통제 자료는 무엇인가?
16. GMLP 원칙을 허가자료에 반영할 때 필수 문서와 기대 수준은 무엇인가?
17. 전처리, 센서 호환성, 특징량, 임계값, 모델 가중치 변경 중 허가변경 대상과 변경관리계획으로 관리 가능한 범위는 무엇인가?
18. 재학습을 허용하지 않는 초기 버전과 향후 변경관리계획을 어느 시점부터 분리해 제출해야 하는가?

### 5. 소프트웨어·보안·상호운용성

19. IEC 62304, ISO 14971, IEC 62366-1, IEC 81001-5-1의 적용 범위와 제출 기대자료는 무엇인가?
20. HL7 FHIR R4 및 ISO/IEEE 11073 기반 입력을 사용할 때 데이터 의미·단위·시간동기·출처 검증 자료는 무엇인가?
21. 병원 내 설치와 클라우드 분석 각각에 요구되는 사이버보안, 접근통제, 감사로그, 업데이트·취약점 대응 자료는 무엇인가?
22. 연결 단절·지연·잘못된 환자연결·단위오류·센서 품질저하 시 안전상태와 UI 표시를 어떤 방식으로 검증해야 하는가?

### 6. 표시사항·사용적합성·시판후

23. 현재 RUO 표시와 장래 의료기기 표시 사이에 사용 가능한/불가능한 문구는 무엇인가?
24. 원신호 확인, 점수 근거, 불확실성, `insufficient_signal`, 데이터 지연을 사용자에게 어떻게 표시해야 하는가?
25. 사용적합성 검증에서 포함할 사용자군, 위해 관련 시나리오와 대표 사용환경은 무엇인가?
26. 시판후 성능감시, 모델 드리프트, 데이터 품질, 경보부담과 이상사례를 어떤 계획으로 관리해야 하는가?
