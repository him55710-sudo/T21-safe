# Intended Use Draft

문서 상태: 연구용 초안<br>
기준일: 2026-09-02<br>
제품 경로: Path B — RUO(research use only) / silent shadow mode

## 1. 현재 연구용 사용 목적

T21 Safe는 다운증후군 환자의 마취 유도 구간에서 수집된 생체신호를 **후향적 또는 silent shadow mode로 분석**하여, 데이터 품질·특징량·후보 위험점수의 기술적 성능과 임상 검증 가능성을 연구하는 소프트웨어 프로토타입이다.

현재 버전은 의료진 화면에 실시간 환자별 위험 알림을 제공하지 않으며, 진단·예후·치료 결정을 지원하거나 임상적 확률을 산출한다고 주장하지 않는다. 연구 출력은 환자 치료가 종료되기 전 임상의에게 공개하지 않는다.

### 현재 사용자와 환경

- 사용자: 승인된 연구자, 데이터 관리자, 임상시험 통계가
- 환경: IRB 승인 및 기관 정보보호 절차가 적용된 연구망 또는 격리 분석환경
- 대상 자료: 다운증후군 환자의 전신마취 또는 진정 관련 후향/전향 관찰자료와 비교군 자료
- 입력 후보: ECG/심박수, PPG/SpO2, 비침습·침습 혈압, 호흡, 마취기·약물·사건 타임스탬프, 제한된 임상 공변량
- 출력: 신호 품질, 특징량, 연구용 점수, 평가 리포트, 오류·결측 플래그
- 데이터 흐름: 모니터/기록시스템의 복사본 → 읽기 전용 수집 → 버전 고정 전처리 → 연구 분석 → 비식별 평가 결과

### 현재 비의도 사용

- 임상 진단, 환자 선별, 예후 판정 또는 개인별 임상 확률 표시
- 경보 장치 또는 기존 생체신호 모니터 경보의 대체
- 약물 선택·용량·투여 시점, 수액, 기도관리 또는 기타 치료 지시
- 펌프·인공호흡기·마취기·모니터의 제어 또는 자동 폐루프 동작
- 임상의에게 보이는 실시간/준실시간 환자별 위험 권고
- 검증되지 않은 기관·연령·수술·진정 환경으로의 일반화
- 공개 데이터만으로 다운증후군 임상 성능이 검증되었다는 주장

## 2. 장래 임상 제품 가설 — 규제 검토용, 승인된 표시사항 아님

> 이 절은 향후 규제기관과 논의할 **제품 가설**이다. 현재 제품의 사용 목적이나 성능 주장이 아니다.

향후 T21 Safe는 적격 의료진이 수술실 또는 시술실에서 다운증후군 환자의 마취 유도 중 생체신호와 임상 정보를 함께 검토할 때, 사전에 정의된 혈역학적 불안정 사건의 가능성이 높아지는 패턴을 보조적으로 표시하는 소프트웨어가 될 수 있다. 출력은 의료진의 독립적 판단과 원신호 검토를 대체하지 않고, 진단·치료·용량결정·기기제어를 직접 수행하지 않는 방향으로만 검토한다.

아래 항목은 임상시험·위험관리·사용적합성 평가와 규제기관 협의 후 확정해야 한다.

- 정확한 대상 연령, 수술/시술 유형, 마취 방법과 제외기준
- 예측/관찰 시간창, 임상 사건 정의와 판정 절차
- 출력의 이름·단위·갱신주기·임계값·불확실성 표시
- 사용할 입력 채널, 최소 신호 품질과 결측 처리
- 사용자 역할, 임상 워크플로와 요구 대응시간
- 경고·주의·금기, 실패 시 안전 상태와 인간 검토 절차

분류: `PRODUCT_ASSUMPTION`

## 3. 설계 불변조건

1. 환자 위험 계산 경로에는 LLM이나 생성형 AI를 포함하지 않는다.
2. 전처리, 특징량, 모델, 임계값, 단위변환과 결측 규칙은 버전·해시로 고정한다.
3. 입력 품질이 사전 기준에 미달하면 점수를 강제로 산출하지 않고 `insufficient_signal` 상태를 낸다.
4. 원신호·기존 모니터 값·데이터 지연을 사용자가 확인할 수 있어야 한다.
5. 연구 성능과 임상 유용성을 분리해 평가하며, 임상 사용 전 외부·전향·silent-mode 검증을 거친다.
6. 배포된 모델을 암묵적으로 재학습하지 않는다. 변경은 사전 정의된 변경관리와 재검증 대상이다.

분류: `PRODUCT_ASSUMPTION`

## 4. 현재 알려진 제한

- 공개 데이터 레지스트리에서 다운증후군 마취 사례를 확실히 식별하면서 고해상도 생체신호와 사건 라벨을 함께 제공하는 자료는 확인하지 못했다. 실제 임상 검증에는 병원 IRB 자료가 필요하다. 분류: `LIMITED_EVIDENCE`
- 다운증후군 소아에서 sevoflurane 유도 중 서맥 증가를 보고한 관찰연구가 있으나, 연구 간 사건정의·대상·마취법이 다르고 제품 성능을 입증하지 않는다. 분류: `VERIFIED_CLINICAL_EVIDENCE`
- 휴식 HRV 연구의 차이가 마취 유도 중 개인별 불안정 예측으로 이어진다는 근거는 없다. 분류: `LIMITED_EVIDENCE`
- 연구 출력은 아직 임상 성능, 임상적 이득, 경보 안전성 또는 일반화 가능성을 확립하지 않았다. 분류: `LIMITED_EVIDENCE`

근거 식별자는 [Evidence Summary](../research/EVIDENCE_SUMMARY.md)와 [Evidence Ledger](../research/EVIDENCE_LEDGER.csv)를 따른다.

## 5. 사용 목적 변경 시 규제 재평가 트리거

- 연구자 전용 결과를 임상의 또는 환자에게 공개
- 실시간/준실시간 표시, 알림, 우선순위 또는 환자 분류 도입
- 질환·사건의 진단, 예측, 확률 또는 임상적 유용성 주장
- 치료·검사·약물·용량·시점 추천
- 펌프 또는 다른 의료기기와의 제어 연결
- 새 환자군, 연령, 병원, 센서 또는 마취 환경으로 확대
- 임계값, 전처리, 특징량, 모델·학습자료의 변경
- 연구 프로토타입의 배포·판매·임상 워크플로 통합

## 6. 표시 문구 초안

> 연구용입니다. 진단 또는 치료 목적으로 사용하지 마십시오. 출력은 임상 경보가 아니며 환자 치료에 사용해서는 안 됩니다. 신호 품질이 불충분하거나 데이터가 지연될 수 있습니다. 원 생체신호와 기존 모니터를 기준으로 하십시오.

이 문구만으로 규제 적용을 회피할 수 있다는 의미는 아니다. 실제 기능, 배포, 홍보, 사용자와 사용 맥락을 함께 검토해야 한다.

분류: `VERIFIED_OFFICIAL_INFORMATION`

## 7. 변경 승인 게이트

연구책임자, 임상안전 책임자, 데이터보호 책임자 및 규제 책임자가 다음을 서면 승인하기 전에는 현재 경계를 변경하지 않는다.

- 새 intended use와 임상 주장
- 위험분석 및 사용 오류 분석
- 검증 프로토콜과 통계분석계획
- 표시·교육·실패 대응 절차
- 규제기관 사전상담 또는 법률 검토 결과
