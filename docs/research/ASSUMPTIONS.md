# T21 Safe 연구 가정 기록

문서 상태: 연구 설계용 초안  
마지막 검토일: 2026-09-02

## 고정된 제품 경계

- 현재 경로는 **Path B: Research Use Only(RUO) / Shadow Mode**다.
- 진단, 치료, 투약, 환자감시 또는 의료진을 대신한 임상 판단에 사용하지 않는다.
- 펌프를 제어하거나 마취제 용량·약물·처치를 추천하지 않는다.
- 초기 출력은 임상적으로 검증된 “위험 확률”이 아니라 버전이 고정된 규칙과 연구 모델이 만든 **Research Instability Index(RII)** 다.
- 실시간 신호 처리와 RII 계산 경로에는 LLM을 넣지 않는다. LLM은 비실시간 문헌 정리와 개발 검토에만 사용할 수 있다.
- 임상 사용 가능성, 유효성, 안전성은 아직 입증되지 않았다. RUO 표시는 규제 적용을 자동으로 면제하지 않는다.

## 데이터 가정

- 공개 데이터에는 DS 마취 사례가 충분하지 않다고 가정한다. 공개 자료는 ingestion, 신호 품질, R-peak, HRV·PPG·PTT feature 검증과 generic event 연구에만 사용한다.
- VitalDB에서 Down syndrome 진단 라벨을 확인할 수 있다고 가정하지 않는다.
- INSPIRE 공개본은 ICD-10-CM Q00–Q99 선천기형·염색체 이상 코드를 제거하므로 DS 식별에 사용하지 않는다.
- MIMIC 임상 테이블에 Q90 계열 코드가 존재할 가능성과 동일 입원의 사용 가능한 파형이 존재하는지는 별개의 조건이다. 승인된 환경에서 환자 수와 파형 교집합을 직접 질의하기 전에는 DS 사례 수를 0 또는 양수로 쓰지 않는다.
- ICU, 성인, 건강 자원자 데이터로 소아 DS 마취 결과에 대한 임상 성능을 주장하지 않는다.
- 데이터셋 간 합치기는 공통 식별자, 시간 정렬, 측정 단위, 환자 중복과 라이선스가 검증된 경우에만 허용한다.
- 원시 환자 데이터는 Git에 커밋하지 않는다. 저장·분석은 기관 승인 환경과 최소권한 정책을 따른다.

## 임상·통계 가정

- 후보 endpoint와 임계값은 임상의·통계가·IRB 검토 전에는 확정값이 아니다.
- 마취 유도 전 안정 구간을 확보할 수 있을 때 환자별 baseline을 계산한다. 확보할 수 없으면 baseline-dependent 출력은 결측으로 처리하며 집단 평균으로 대체하지 않는다.
- 연구 window, prediction horizon, SQI 기준과 임계값은 훈련/개발 자료에서 사전 고정하고 test set에서 조정하지 않는다.
- 같은 환자의 여러 시술은 하나의 split에만 속한다. 최종 성능 판단에는 시간적 분리와 외부기관 검증이 필요하다.
- 희귀 사건 때문에 AUROC만으로 판단하지 않고 AUPRC, 고정 false-alarm rate에서의 민감도, 시간당 오경보, lead time, calibration, Brier score를 함께 보고한다.
- 문헌별 인구, 마취제, 관찰창과 endpoint가 달라 사건률을 단순 합산하거나 메타분석처럼 시각화하지 않는다. 본 문서군은 이질적 근거를 audit table로 제시한다.

## 근거 해석 가정

- sevoflurane 유도 중 소아 DS 서맥 근거를 모든 연령·약제·마취 단계에 일반화하지 않는다.
- sympathetic failure는 한 전향 연구의 관찰과 연결되지만 단일 확정 기전으로 간주하지 않는다. vagal excess와 baroreflex impairment도 연구 맥락과 한계를 함께 표시한다.
- resting HRV만으로 개인의 DS 마취 위험을 판정할 수 없다고 본다. LF/HF를 단순한 “교감/부교감 균형”으로 해석하지 않는다.
- atropine hypersensitivity, 구체적 마취제 감량률, 특정 약물 우선 사용은 현재 검증된 제품 주장으로 채택하지 않는다.

## 문서 위치 가정

- 요청된 `ASSUMPTIONS.md`는 브랜치 소유권을 지키기 위해 루트가 아니라 `docs/research/ASSUMPTIONS.md`에 둔다.
- 제조사 제품 페이지의 성능 문구는 임상 근거가 아니라 공식 제품 설명/마케팅 주장으로 분류하고 독립 검증 결과처럼 재사용하지 않는다.
- 2026-09-02 이후 바뀔 수 있는 데이터 버전·규제 문서는 실제 제출 또는 연구 시작 직전에 다시 확인한다.
